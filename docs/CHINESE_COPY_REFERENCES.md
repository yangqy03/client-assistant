# 中文回访文案参考与改写依据

更新日期：2026-11-02。应用 / 提示词版本：0.1.2。

这些资料在设计阶段人工阅读，未接入应用运行过程，也未用于建立 RAG。公开教学话术不能当作奢侈品牌真实私聊记录，也不能据此声称转化率改善。

## 1. 接续已有选购需求

来源：[群应用 SCRM《贺学友：这样跟进BC类客户，签单率翻倍！》](https://www.wescrm.com/siyuzhishiku/siyuyunying/9165.html)，第四节“沉睡客户激活”。

采用的结构：回顾已知需求，提供与之相关的帮助，再询问需求是否仍然存在。来源属于偏 B2B 的销售教学；本项目不采用其施压或业绩导向表达，不采用标题中的效果主张。

本项目原创改写：林女士，您好，上次您提到想找一只简洁的通勤包，不知道现在有没有选到合适的？如果还在看，我可以按您的需求帮您再看看。

适用条件：明确提供了此前咨询简洁通勤手袋的历史记录。不得编造新品到货、已准备好推荐、预留商品或客户目前仍有购买意愿。

## 2. 从已购商品的使用体验切入

来源：[《100条实战销售破冰话术，按不同沟通场景分类，可直接复制》](https://www.toutiao.com/article/7668059967080890920/)，第61条，属于公开中文销售话术示例。

采用的结构：明确已购商品，询问使用体验，提供问题跟进渠道。这里借鉴交流方式，不将公开模板视为效果验证。

本项目原创改写：林女士，您好，之前那只折影手袋最近用得还顺手吗？如果有使用或养护方面的问题，可以微信告诉我，我帮您确认一下。

适用条件：输入有已确认的折影手袋购买记录。不得自行承诺免费护理、保修权益、维修时效或未经确认的养护方法。

## 3. 有事实再个性化，没有事实就询问当前需要

来源：[Zoho CRM《沉默客户怎么唤醒？用“客户分层+触发器”做自动回访》](https://www.zoho.com.cn/crm/articles/silent-customer0209.html)，第四节“内容与频率怎么设计”。

采用的原则：围绕使用体验或现有需求沟通，并给出具体、容易回应的下一步。本项目不直接套用其 B2B 客户分层周期或自动触达频率。

本项目原创改写：林女士，您好，好久没联系了。如果最近有挑选手袋的需要，可以告诉我您打算在什么场合使用，我帮您一起看看。

适用条件：只知道久未到店，没有可核实的具体咨询或购买记录。

## 实现边界

- 三套背景均为本项目编写的虚构记录，界面可显式加载和检查。
- 固定示例只有在画像、会话记录、产品信息、沟通目的四个字段与相应预设完全一致时，才使用该套历史细节。
- 任一背景字段被改动，固定示例退回无历史引用的通用表达；这不代表系统理解了自由文本。
- 实时模式仍将用户输入直接提供给模型，并通过提示词约束事实使用；尚未进行真实模型验证。
- 不再使用“不必特意回复”等刻意结束对话的句子，也不通过反复催问制造回复压力。

## 4. 用户补充：AC汽车的服务顾问沟通案例

来源：[黄灿《实战案例丨SA的销售话术可以学的会吗？》](https://acqiche.com/archives/38206.html)，AC汽车，2020年9月4日。

文章讨论的是汽服门店服务顾问，不是奢侈品导购。其“问好、问询、介绍、异议”框架，以及先了解客户感受、再说明具体解决方式的案例，可作为跨行业沟通参考；不能视为本项目场景中的实证结果。

本项目的应用判断：

- 不是把四步机械塞进每条微信，而是根据会话当前阶段写下一条合适的回应。已有明确需求时避免重复盘问。
- 推荐或回访应围绕客户已陈述的使用场景、顾虑或体验，并说明顾问具体能提供什么帮助。
- 价格异议先回应客户顾虑，再以输入中可核实的事实解释或询问必要信息，不靠堆砌形容词。
- 原文的汽车故障判断、优惠和服务承诺不能直接迁移。项目仍只使用已提供的产品事实，不自创折扣、赠品或保修。
- 将来进行角色扮演和新输入测试，检查文案是否真正接住客户的问题；目前尚未完成这种真实模型评估。

本次仅补充资料与方法论记录，应用和提示词仍为0.1.2，没有新增模型运行或质量分数。

## 5. 用户补充：销售易社区《奢侈品销售的技巧及话术》

来源：[销售易社区文章](https://club.xiaoshouyi.com/thread-475-1-1.html)。网页抓取超时后，通过浏览器读取公开正文；文末标明内容为转载，不能作为品牌官方训练材料或效果证明。

采用的设计思路是把产品与客户已经说明的具体使用情境关联，而不只罗列商品名称。项目不采纳阶层优越、财富象征、性别或婚姻刻板印象、保值承诺等说服方式，也不复制文中的真实品牌或人物案例。场景描写只能建立在输入事实之上。

落地版本0.1.3：产品推荐预设用已确认的雾灰配色、尺寸、手提/肩背信息回应通勤场景；对未知重量和装载情况明确需要核实。未知事实不靠想象补齐。

## 6. 用户补充：Shopify 中文《奢侈品营销：策略、技巧和实例》

来源：[Shopify 中文文章](https://www.shopify.com/zh/blog/luxury-marketing)。文章讨论品质、工艺、叙事与整体购物体验等营销要素；它是营销指南，不是中文微信话术效果研究。

本项目将其转化为“有证据的细节＋个人使用场景＋服务体验”：只有输入明确提供工艺或故事才可提及，不编造历史、产地或手工。活动邀约突出已确认的体验安排；价格异议先正面回答折扣，再回应预算，不把普通营销中的稀缺营造变成虚假库存或名额。

落地版本0.1.3：新增已确认工艺预览和预算/无折扣政策两套背景、对应的固定示例，以及实时提示词规则。以上是本项目的取舍和改写，不主张两篇资料认可本应用，也不据此声称销售效果改善。
